# Bingo Cubano — Demo gratis

Demo del juego Bingo Cubano (mini-app para QvaPay, en desarrollo).

- Juega rondas completas **sin dinero real**: el saldo es de demostración, el cartón cuesta $0.10 ficticios, la voz canta los números, y tú marcas tu cartón y cantas bingo.
- La versión real, con premios en saldo QvaPay, está en desarrollo y necesita la aprobación de QvaPay.
- Juega la demo aquí: https://mki5.github.io/bingo-cubano-demo/
